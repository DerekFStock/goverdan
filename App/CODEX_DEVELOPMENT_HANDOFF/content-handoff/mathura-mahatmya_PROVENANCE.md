# Mathurā-māhātmya 418–423 + Context — Source Package Provenance

## Status
NORMALIZED / NOT YET APP_READY

The Sanskrit root text for MM 416–425 has been structured and verified against
the project's clean searchable Mathurā-māhātmya witness. The core Rādhā-kuṇḍa
range is MM 418–423.

## Primary witness
`mathura_mahatmya_-_rupa_gosvamin.docx`

The core passage occurs across source pages 57–58.

## Rūpa's attributions
The package preserves the source labels as they appear in Rūpa's compilation:
- MM 418: Ādi-varāha
- MM 419: Mathurā-khaṇḍa
- MM 420–423: Padma Purāṇa / Kārttika-māhātmya stream

These are preserved as Rūpa Gosvāmī's attributions. They are not treated as
independent proof that the wording has been checked in every extant Purāṇa
recension.

## Translation provenance
Already controlled in project research:
- MM 418: controlled project sense in RS-01
- MM 420: approved project translation in RS-01
- MM 421 second half: approved project translation in RS-01
- MM 422 first half: controlled in RS-03 via CC Madhya 18.8

New literal working translations were added for MM 419, the second half of MM
422, and MM 423. The first half of MM 421 remains untranslated in the release
field pending philological review.

Because not every core translation is yet approved, this package is deliberately
marked NORMALIZED rather than APP_READY.

## Context
MM 416–417 are retained before the core unit to show the transition from
Govinda-kuṇḍa/Annakūṭa material into the Rādhā-kuṇḍa subsection.
MM 424–425 are retained after it to show the transition into Akrūra-tīrtha.
