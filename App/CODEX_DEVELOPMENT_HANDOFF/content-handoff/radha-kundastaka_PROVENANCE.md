# Rādhā-kuṇḍāṣṭaka 1–8 — App Source Package Provenance

## Status
APP_READY source package for the Rādhā-kuṇḍa Story MVP.

## Root text
The transliterated Sanskrit is based on the project Stavāvalī witness
`stavavali_-_raghunatha_dasa_gosvamin 2.docx.pdf`, where
Śrī Rādhā-kuṇḍāṣṭakam appears on PDF pages 8–9.

## Normalization
- Unicode normalized for app use.
- Verse and pāda lineation normalized.
- Verse 3 uses the project-controlled reading `uccaiḥ`; the searchable
  Stavāvalī witness contains the apparent transcription/OCR form `ucaaiḥ`.

## Translation
The English translations are the approved Govardhana Pilgrimage Project
research translations preserved in
`Radhakunda_RS-02_Theological_Architecture_of_the_Manifestation_Lila_v1.0`,
Primary quotation packet, pp. 12–14.

They are research translations intended to identify theological content,
not metrical literary translations.

## Scope
This package contains verses 1–8. Verse 9, the phala-śruti, remains in the
Stavāvalī witness but is outside the current MVP package.
