# CODEX TASK 014 — MVP Stabilization and 1.0 Gate

**Milestone:** 14 — MVP Stabilization  
**Status:** Final gate only after the intended approved Rādhā-kuṇḍa Story/source corpus has been explicitly completed  
**Controlling documents:** MVP-BASELINE v1.0; MVP-00 through MVP-08 v1.0; all approved amendments; prior task handoffs

## Goal

Stabilize the private Rādhā-kuṇḍa Story MVP for the internal v1.0 gate without adding new scope.

## Required readiness checks

- complete intended approved Rādhā-kuṇḍa Story corpus is present;
- every visible Citation resolves to a VERIFIED canonical Passage as required for the intended release package;
- Library and Search cover included sources;
- Bookmarks and reading positions are reliable;
- Unicode rendering is reviewed;
- original witnesses work where included;
- no normal-flow crashes;
- content build/audit is clean;
- all automated tests pass;
- actual iPhone reading review passes.

## Required work

Only stabilization work necessary to satisfy existing specifications:

- fix defects/regressions;
- improve test coverage for discovered defects;
- run clean content rebuild and citation audit;
- verify read-only content vs writable user-state separation;
- verify offline operation/no networking layer;
- verify excluded features remain absent;
- produce a release-readiness report.

## Forbidden changes

No new feature development, no scope expansion, no Govardhana/maps/GPS/Kindle/web/backend/AI/social/analytics, and no scholarly-content invention or silent status promotion.

## Acceptance criteria

All MVP-08 Milestone 14 criteria and the MVP completion definition pass, with a written list of any remaining non-blocking limitations.

## Final handoff

Report the full test matrix, device/build results, content/citation audit, remaining limitations, and whether the internal v1.0 gate is met. Then **stop** for final user approval. Do not declare a broader public release.
