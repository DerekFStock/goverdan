# Śrī Dāna-keli-cintāmaṇi — Reader Source Provenance

## Reader scope

This package intentionally creates **one and only one** app-reader work:

`work.dana-keli-cintamani`

There are no comparison copies, no alternate reader editions, and no separate commentary work.

## Source

The Sanskrit root text was extracted from the user-supplied file:

`dana-keli-cintamani_-_raghunatha_dasa_gosvamin(1).docx`

The DOCX contains both root verses and commentary. Only paragraphs explicitly styled as root verse quotations
were used to prepare the working English translation. Sanskrit and commentary remain outside the runtime Work.

## Canonical passage scope

- 175 English verse translations
- `passage.dana-keli-cintamani.1` through `passage.dana-keli-cintamani.175`
- one preferred reading edition:
  `edition.dana-keli-cintamani.project-reading-v1`

## Numbering normalization

The uploaded source DOCX contains a local numbering slip after verse 163: the next six root verses are printed 163, 164, 165, 166, 167, 168, followed by 170. The project reader canonicalizes those six sequentially as 164–169, preserving a continuous 1–175 passage sequence. No alternate reader copy is created.

This is a numbering normalization only. It does not create a second text or comparison edition.

## Translation

The English is a fresh `WORKING_PROJECT` translation prepared for the Govardhana Pilgrimage reader.
It is suitable for development and personal reading but remains `PENDING_PROJECT_APPROVAL` rather than
being represented as a publication-critical translation.

## Runtime intent

The app should expose one English-only Library/Source Reader entry titled **Dāna-keli-cintāmaṇi** with verses 1–175.
No witness selector, edition selector, parallel-text comparison, or commentary selector is required.
